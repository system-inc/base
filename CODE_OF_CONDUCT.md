# Code of Conduct

This project has adopted the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1, as its Code of Conduct. We are committed to providing a welcoming, respectful, and harassment-free experience for everyone who participates in this community.

The full standards of expected behavior, unacceptable behavior, and the enforcement guidelines maintainers follow are documented in the canonical text:

> https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Scope

This Code of Conduct applies within all project spaces — the repository, issues, pull requests, and discussions — and also applies when an individual is officially representing the project in public spaces.

## Reporting

If you experience or witness unacceptable behavior, please report it to the maintainers at **contact@base-framework.dev**. All reports will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and security of anyone who reports an incident.
